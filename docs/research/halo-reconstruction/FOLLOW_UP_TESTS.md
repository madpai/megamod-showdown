# Independent follow-up tests

These are **proposals**, not tests added during this research. Use original synthetic fixtures for public CI. Compare against the owner's Trial PC build/data only in private, legal test environments where a Halo compatibility claim matters. A 2342 reconstructed result is a hypothesis, not the expected Trial answer. Keep Showdown-specific rules separately labelled.

| Priority / hypothesis | Independent fixture and observation | Confirms / refutes | Evidence / action |
| --- | --- | --- | --- |
| **1. Stale reference after slot reuse** | X1 already tests stale world-entity handles across round reset. For a **future dynamically allocated pool**, queue an event to a typed handle, delete its object, reuse the slot for a different instance/kind, then dispatch; include generation wrap policy. | Only the live generation receives the event; an old or cross-kind handle fails closed. Do not duplicate X1's reset test. | [2342 datum lookup](https://github.com/bnunu/halo-1/blob/52659b6/source/memory/data.c#L111-L169), [landed X1 tests](../../WORLD_ENTITIES.md#tests); **ADD TEST** only with a new dynamic pool. |
| **2. Authored ID versus local dense order** | X1 already tests reordered placements and stable authored links; X2 already tests changed binary geometry with a byte-identical manifest and rejects the mismatched peer. When another authored entity family or played package field is added, permute its source order and mutate its binary/gameplay content. | The authored link still resolves; a gameplay-relevant difference changes the compatibility key. | [Landed X1/X2 evidence](../../WORLD_ENTITIES.md#x2-tests), [dense-index audit](../DENSE_INDEX_HAZARDS.md); **ADD TEST** only for new content domains. |
| **3. Spawn/delete phase ordering** | In an instrumented synthetic match, create a projectile/object from an event or script-equivalent callback during one tick, then delete its parent before the next. Record first update, collision and cleanup tick. Run at 30/60/120 display rates with the same simulation inputs. | Deterministic phase contract; no extra update, leaked child or display-rate dependency. Compare private Trial observation separately. | [2342 object update](https://github.com/bnunu/halo-1/blob/52659b6/source/objects/objects.c#L4122-L4240); **ADD TEST**. |
| **4. Tick phase trace** | Add temporary **test-only instrumentation later** to record input accepted, unit movement, AI decision, weapon fire, projectile impact, damage, CTF rule transition and event emission in one synthetic fixture. Compare repeated headless/Android runs. | Stable MegaMod order and event IDs. A separate private Trial probe can check the 2342 `game_tick` ordering hypothesis without porting code. | [2342 tick](https://github.com/bnunu/halo-1/blob/52659b6/source/game/game.c#L433-L475); **ADD TEST**. |
| **5. Projectile, grenade and melee timing** | Use a synthetic wall/body fixture with known distances and fixed input sequence. Sweep tick step and frame pacing; record spawn tick, travel/impact, fuse, melee hit, weapon cooldown and damage event. On private Trial, use equivalent tagged items where possible. | Timing and collision outcomes remain stable across render rates; Trial differences identify compatibility work. | [2342 weapons/projectiles](https://github.com/bnunu/halo-1/tree/52659b6/source/items), [MegaMod invented ledger](../../HANDOFF.md); **INVESTIGATE LATER**. |
| **6. Seat and vehicle transitions** | In a flat synthetic world, board as driver/passenger/gunner, fire, exit while moving, die in seat and respawn; include a vehicle at pool capacity. Log seat ownership, velocity, damage and authoritative event order. Compare private Trial only for Halo seats. | No duplicated occupant, stale reference, camera discontinuity or divergent authority state; known Showdown hull durability remains intentionally independent. | [2342 units/vehicles](https://github.com/bnunu/halo-1/tree/52659b6/source/units); **ADD TEST** at relevant roadmap slice. |
| **7. Damage and CTF rule edges** | Synthetic flag stands and two players: simultaneous pickup/drop/return/capture and death at timer boundary; test shield depletion/recharge and blast plus direct-hit ordering. Record score, state, replication and visible event. Repeat private Trial observations for Halo compatibility. | One authoritative transition per tick; durable late-join state matches host. Any Trial difference gets a version label before becoming a bug. | [2342 CTF](https://github.com/bnunu/halo-1/blob/52659b6/source/game/game_engine_ctf.c), [damage](https://github.com/bnunu/halo-1/blob/52659b6/source/objects/damage.c); **INVESTIGATE LATER**. |
| **8. Interpolation discontinuities** | Replay a deterministic headless trace through desktop/Android renderers with teleport, respawn, vehicle seat, camera cut and packet correction. Capture transform samples at 30/60/120 display Hz. | No visual sweep through a wall or stale pre-respawn pose; simulation hash unchanged by render cadence. Measure actual visual delay. | [Universal interpolation](https://github.com/cybersecurity/halo-ce-universal/blob/13d1ae2/port/linux/game/render_interpolation.c); **ADD TEST** during desktop parity. |
| **9. AI budget visibility** | On an original synthetic nav world, run 0/8/32 bots with blocked and reachable targets. Record per-tick path attempts, perception checks, time budget, dormant state, chosen action and eventual progress. | Cost is bounded, failures do not consume all work, and telemetry explains stalls. No Halo encounter AI needs importing. | [2342 actor scheduling](https://github.com/bnunu/halo-1/blob/52659b6/source/ai/actors.c#L4233-L4257); **DOCUMENT / ADD TEST** when bot work resumes. |
| **10. Join, late join and event/state split** | X1/X2 already test late join for mover state and changed world content. Extend the fixture to a dropped flag, exploded prop, occupied seat and in-flight projectile; add loss/reordering/duplicate packets and max-client pressure. | Late join receives each durable host state; transient FX is not replayed as authoritative state; reliable queues remain bounded. | [MegaMod v10 contract](../../CONTENT_COMPATIBILITY.md), [landed X2 late-join test](../../WORLD_ENTITIES.md#x2-tests), [fork stress method](https://github.com/bnunu/halo-ce-universal/blob/f2fa457/tools/system_link_bots.py); **ADD TEST** when network scope expands. |
| **11. Android/platform parity** | Compile the same synthetic asset-free match for headless Linux and Android emulator/device. Feed recorded inputs and compare gameplay event log/state hash; test file import, app pause/resume, surface recreation and 4 KB/16 KB page devices where available. | Gameplay parity or a clearly localized platform-only difference. The universal port's page-size limitation is a warning about embedded assumptions, not a known MegaMod defect. | [Universal Android limits](https://github.com/cybersecurity/halo-ce-universal/blob/13d1ae2/port/android/README.md#known-limitations); **INVESTIGATE LATER**. |

**Sequencing:** X1/X2 already cover the baseline cases in tests 1–2 and the mover part of test 10. Extend them only for new domains. Tests 3–4 fit future shared-tick verification; tests 5–7 serve later Open Halo accuracy work. Tests 8–11 attach to desktop, bot, networking and Android work when scheduled. This research adds no gate and postpones no scheduled work.
