# Reconstructed 2342 subsystem map

All rows describe the [bnunu 2342 reconstruction](https://github.com/bnunu/halo-1/tree/52659b6/source) unless labeled port. Names are navigational evidence, not a claim that every function exactly matches the Xbox binary. “Equivalent” means MegaMod has a related capability, not identical behavior. For MegaMod's current boundaries see the [engine map](../../ENGINE_ARCHITECTURE.md) and [vision](../../MEGAMOD_VISION.md).

### Update hierarchy, not a module diagram mandate

The reconstructed [tick](https://github.com/bnunu/halo-1/blob/52659b6/source/game/game.c#L433-L475) calls units and AI before `objects_update`; object dispatch then reaches weapon, projectile, vehicle and damage update paths. Thus a flat directory list is **not** the execution order. `objects_update` handles root objects, recurses into children, treats newly created/deleted objects specially, and uses active BSP clusters; see [object update](https://github.com/bnunu/halo-1/blob/52659b6/source/objects/objects.c#L4122-L4240). This is reconstructed-source evidence for build 2342 and needs Trial validation.

The separate [`game_frame`](https://github.com/bnunu/halo-1/blob/52659b6/source/game/game.c#L987-L1018) advances sound and scenario frame work outside `game_tick`; the main loop owns rendering. The native port adds high-refresh interpolation. This distinction matters when comparing simulation logs with visual or audio observations.
